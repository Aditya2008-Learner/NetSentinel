Collector Setup & Instructions

To stream live telemetry from your Windows computer into Net Sentinel:

  1. Ensure Npcap is installed on your Windows machine.
  2. Navigate to the collector/ folder in the repository.
  3. Run python main.py --list-interfaces to view network adapters.
  4. Start monitoring with python main.py --interface 0.
